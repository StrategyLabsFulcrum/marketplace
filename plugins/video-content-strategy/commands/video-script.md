# /video-script

Write a full script or detailed outline for a specific video — organic content, paid ad, YouTube episode, TikTok, or UGC brief.

## How to Invoke

**Script from a campaign brief:**
```
/video-script campaigns/2026-03-spring-launch/brief.md
```

**Standalone with description:**
```
/video-script 60-second TikTok ad, before/after hook, targeting problem-aware audience for [product]
```

**YouTube tutorial:**
```
/video-script YouTube tutorial: how to [topic], 8-10 minutes, search-optimized
```

**UGC creator brief:**
```
/video-script UGC brief for [product] — 3 hook variations, 30-60 sec, authentic creator style
```

**Video ad with multiple hooks:**
```
/video-script 30-sec Meta video ad — write 3 hook variations for A/B testing
```

## What You Get

- Full two-column script (VISUAL | AUDIO) or inline format for shorter videos
- On-screen text overlay copy
- CTA options
- Production notes (camera angles, B-roll suggestions, props needed)
- For ads: multiple hook variations for testing
- For UGC: creator brief with dos/don'ts and talking points (not a rigid script)

## Output Location

Saved to `campaigns/[slug]/video-strategy/scripts/` or specified folder.
