# v1.4 — File-by-File Change Audit

This document maps every file in the v1.3 codebase to the changes required for v1.4. Use it as a build checklist.

**Scope key:**
- 🔴 **Heavy** — substantial rewrite or new logic
- 🟡 **Moderate** — multiple sections updated
- 🟢 **Light** — small targeted edits
- ⚪ **None** — no change required
- ➕ **New** — new file
- ➖ **Deprecated** — file removed; data migrates elsewhere
