# /multi-model

Send a single creative brief to multiple AI models simultaneously. Compare outputs side-by-side and pick the best result — or combine elements from different models.

## Usage

```
/multi-model [brief description]
```

## Examples

```
/multi-model Hero image for our summer campaign — woman on beach with our product, golden hour
/multi-model 15-second product demo video for TikTok — quick cuts, trending aesthetic
/multi-model Dashboard mockup showing Q2 performance metrics in our brand colors
```

## What Happens

1. You describe what you need (or paste an existing brief)
2. The engine translates the brief into optimized prompts for each connected model
3. Each prompt is tailored to the model's syntax and strengths
4. All prompts are presented in a comparison document with:
   - Per-model optimized prompts
   - Expected output description for each
   - Recommendation for best single model and best combination
5. You choose which to generate, then compare real outputs

## Comparison Output

The comparison document shows:
- **Why each model** — what it will do well with this specific brief
- **Optimized prompt** — tailored to each model's prompt format
- **Expected strengths** — what will likely be best about this model's output
- **Expected limitations** — what might need refinement
- **Recommendation** — which model(s) to generate with first
