# Merchandise Production Specifications

Technical requirements by production method and product type.

---

## Screen Printing

The industry standard for high-volume apparel. Each color is a separate ink layer applied through a mesh screen.

### File Requirements
- Format: Vector (Adobe Illustrator AI or EPS, SVG) — absolutely required
- Why: Vector art allows each color to be separated into individual layers; no rasterization at any size
- If starting from raster: must be professionally redrawn as vector before screen print production
- Color mode: Spot color (Pantone) — not CMYK, not RGB
- Resolution (if rasterized elements are unavoidable): 300 DPI at print size minimum; 1200 DPI ideal

### Color Specifications
- Each ink color = one screen = one additional cost
- 1 color: Most economical; bold and intentional look
- 2–4 colors: Standard range for branded merchandise; good quality/cost balance
- 5–6 colors: Elevated; for hero products worth the investment
- 7+ colors: Premium/special; evaluate whether DTG or sublimation is more appropriate

**Pantone (PMS) color specification is required.** The printer cannot match brand colors from hex or CMYK values — Pantone ensures accurate color matching across print runs.

Common brand Pantone matching situations:
- Request a physical proof (strike-off) on the garment color before approving a full run
- Colors look different on dark vs. light garment backgrounds — always specify garment color when defining ink colors
- White ink is opaque and prints first on dark garments (adds to ink count); do not use white on white garments

### Special Screen Print Techniques
| Technique | Effect | Notes |
|-----------|--------|-------|
| Soft hand | Softer feel; inks blend with fabric | Standard finish for most applications |
| Puff ink | 3D raised texture | Works on flat, simple graphics; not fine detail |
| Foil | Metallic finish | Requires adhesive base; bold areas only |
| Discharge | Removes dye; very soft finish | Only works on 100% cotton; earthy/vintage look |
| Glitter | Sparkle effect | Add to any ink area; best on fashion/lifestyle items |
| Glow-in-the-dark | Glows after light exposure | Novelty; best for seasonal/event merchandise |

### Apparel Print Size Limits
| Location | Typical max print area |
|---------|----------------------|
| Full front (adult tee) | 13" × 17" |
| Left chest | 4" × 4" |
| Full back | 14" × 18" |
| Sleeve | 4" × 14" (varies by sleeve length) |
| Pocket area | 3.5" × 3.5" |
| Hood | 10" × 5" |

## Direct to Garment (DTG)

Inkjet printing directly onto fabric. Produces full-color photographic quality designs.

### File Requirements
- Format: PNG with transparent background (preferred) or layered PSD/TIFF
- Resolution: 300 DPI minimum at print size; 150 DPI minimum for larger prints
- Color mode: sRGB (DTG printers use RGB workflow)
- No vector requirement — raster files are fine
- Transparency: Use PNG alpha channel; remove all white backgrounds before submitting

### Color Specifications
- Unlimited colors — no Pantone specification needed
- Can print photographic gradients, drop shadows, complex imagery
- Full-color art files (JPEG source images, Photoshop composites) translate directly

### DTG Limitations
- **White garments**: Best results; inks are transparent-ish; full vibrancy
- **Dark garments**: Requires white underbase printed first (adds cost); colors slightly muted vs. light garments; never as vibrant as on white
- **Texture/weave**: Coarse fabric textures (hoodies, thick knits) show fabric grain in print; best results on smooth jersey
- **Fabric content**: 100% cotton = best results; 50/50 blends = acceptable; 100% polyester = poor results (sublimation is better for polyester)
- **Durability**: DTG prints fade faster than screen print; wash inside-out in cold water; tumble dry low

### When to Choose DTG vs. Screen Print
| Situation | Choose |
|-----------|--------|
| Complex, full-color artwork | DTG |
| Simple 1–4 color logo/graphic | Screen print |
| Small run (<24 units) | DTG |
| Large run (100+ units) | Screen print |
| Photographic imagery | DTG |
| Bold, flat graphics | Screen print |
| Dark garments with vibrant color | Screen print (DTG underbase is less vibrant) |

## Embroidery

Thread stitched into fabric. Premium, durable, elevated feel.

### File Requirements
- Format: Vector (AI, EPS) or high-contrast raster at 300 DPI
- The vendor will convert your artwork to an embroidery "DST/PES file" (digitizing) — this is an additional service cost
- Digitizing cost: typically $10–25 per design; one-time; reusable for future orders
- Simple vector = easier digitizing = more accurate result = lower digitizing cost

### Design Constraints for Embroidery
- **Minimum element size**: 0.25" for filled areas; 0.125" for outlines
- **Fine detail is lost**: No thin serifs, no hairlines, no complex illustrations — they fill in or become unrecognizable
- **Text minimum**: 0.25" tall for legibility; 0.35" for small sizes; bold fonts only
- **Gradients**: Not possible with standard embroidery — use flat color blocking or blended shading (limited)
- **Maximum colors**: 15 standard thread colors (more is possible but adds complexity and cost)
- **Thread colors**: Specified from thread manufacturer charts (Madeira, Isacord, Robison-Anton) — ask vendor for their thread chart

### Stitch Types
| Type | Use |
|------|-----|
| Satin stitch | Clean edges on letters and outlines; 2–8mm wide |
| Fill stitch (tatami) | Large filled areas; creates consistent texture |
| Running stitch | Outlines and fine lines; single thread path |
| 3D puff | Foam underlay raises design above surface; bold graphics only |

### Best Products for Embroidery
- Structured hats (front panel): Most common; professional and durable
- Polos: Left chest; classic brand placement
- Jackets: Left chest or full back; premium feel
- Bags/totes: Front panel; elevated alternative to screen print
- Patches: Embroidered and sewn or ironed on

### Embroidery Size Guidelines by Location
| Location | Typical size |
|---------|-------------|
| Hat front panel | 2"–3.5" wide × 1.5"–2.5" tall |
| Left chest (apparel) | 3"–4" wide × 2"–3" tall |
| Full back | Up to 12"–14" wide (large designs) |
| Sleeve | 2"–4" tall |

## Dye Sublimation

Heat-transfers dye into polyester fibers. Creates full-color, all-over prints (AOP) with no feel to the print — it's in the fabric.

### File Requirements
- Format: High-resolution JPEG, PNG, or TIFF
- Resolution: 150 DPI minimum at actual print size; 300 DPI preferred
- Color mode: sRGB
- No limits on colors or complexity

### Sublimation Rules
- **Polyester only**: Sublimation dye bonds to polyester fibers. 100% polyester = best results. Does not work on cotton.
- **White or light-colored substrate only**: Inks are transparent — they tint the fabric color. Dark fabrics produce muted, washed results. Sublimation only works on white or very light substrates.
- **Cannot print white**: White in the design = the white substrate showing through. Plan designs with white substrate as background.
- **Full-wrap capability**: Sublimation wraps completely around cylindrical products (drinkware) and can cover entire garments (all-over print shirts, performance wear, swimwear)

### Best Sublimation Products
- Performance/athletic wear (polyester jerseys, shorts)
- All-over print t-shirts (AOP) — dramatic, high-impact designs
- Drinkware (mugs, tumblers — with coated white interior)
- Phone cases
- Pillows and soft home goods
- Flags and banners
- Mouse pads

## Vinyl Cutting (Stickers and Decals)

Cuts shapes from adhesive vinyl sheet. Results in clean, solid-color graphics.

### File Requirements
- Format: Vector ONLY (AI, EPS, SVG with all paths clean and joined)
- No gradients, no raster effects — cut vinyl is flat color
- Color = number of vinyl colors cut (each color is a separate cut layer)
- Minimum line thickness: 0.03" (thinner cuts won't hold; too fragile)
- Minimum element size: 0.125" at finished size

### Sticker Production Methods

**Die-cut vinyl (contour cut):**
- Cut follows the exact outline of the artwork
- Result: sticker shape matches the graphic — no rectangular background
- File: vector art with a defined cut path (offset from artwork by 0.125")

**Kiss-cut on sheet:**
- Cut goes through the sticker layer but not the backing paper
- Multiple stickers on one sheet; easy to peel
- Good for sticker packs

**Clear vinyl:**
- Transparent background; sticker appears "floating" when applied
- Requires dark outlines or the design to be legible without a white background

**Holographic vinyl:**
- Rainbow-reflective background; works best with simple graphics and bold colors

### Vinyl Sticker File Setup
```
Artboard: Sticker finished size
Art layer: Artwork at 100% size
Bleed layer: 0.125" beyond artwork edge (for print)
Cut line: 0.0625" offset from artwork edge (or further for white border)
Safe zone: All critical art 0.0625" inside cut line
Color mode: CMYK (most sticker production is CMYK inkjet)
Resolution (if raster elements): 1500+ DPI at sticker print size
```

## Print-on-Demand Platform File Standards

Each POD platform has specific requirements — always check the product template for the specific item.

### Printful
- Format: PNG (preferred), JPG, or SVG
- Color mode: sRGB
- Resolution: 150 DPI at print size minimum; 300 DPI preferred
- Transparent background: Required for all t-shirts and cut-and-sew products
- File size limit: 200 MB

### Printify
- Format: PNG with transparent background
- Color mode: sRGB
- Resolution: 300 DPI at print size
- Specific templates available per product — always download template first

### Common POD Product Templates (request from platform)
Each product has a print template specifying:
- Print area dimensions and position
- Bleed and safe zone
- Mockup images for review
- Any positioning restrictions (avoid handles, seams, etc.)

|--------|-------------|-------------|-------|
| Screen print (1 color) | $6–10 | 24+ | Lower at higher quantities |

| DTG | $18–30 | 1 | No minimums; premium at low volume |
| Embroidery (left chest) | $12–20 | 12+ | Digitizing fee (once) + per-unit |
| Sublimation (full AOP tee) | $22–35 | 1 | Polyester only |
| Die-cut stickers (3") | $1.50–4 | 25+ | Lower at 100+ |
| Hard enamel pin (1.25") | $3–6 | 100 minimum | |
| Embroidered patch (3") | $2–4 | 50 minimum | |
| Printful POD tee | $12–20 | 1 | Retail price typically $28–45 |

**Volume break guidance:**
- Under 24 units: POD or DTG
- 24–99 units: Screen print becomes competitive; consider for proven designs
- 100+ units: Screen print strongly preferred on cost; embroidery for premium items
- 500+ units: Request custom quotes; significant cost reductions available
