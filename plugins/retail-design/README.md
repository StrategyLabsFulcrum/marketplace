# Retail Designer

Designs branded merchandise and retail products — apparel, stickers, accessories, and anything a brand can sell or gift. Produces complete production-ready specifications for every production method. Specialist agent directed by the Art Director.

## What It Does

1. Loads brand standards (logo variations, Pantone/CMYK/hex values)
2. Determines the design strategy (brand-led, graphic-led, or campaign-led)
3. Produces complete design specifications for every product in scope
4. Specifies production method requirements and constraints
5. Provides POD platform guidance when applicable
6. Addresses merchandise collection cohesion when multiple products are in scope

## Products Covered

| Category | Items |
|---------|-------|
| Apparel | T-shirts, hoodies, sweatshirts, hats, jackets, polos |
| Accessories | Tote bags, backpacks |
| Drinkware | Mugs, tumblers, water bottles, can coolers |
| Stickers | Die-cut, kiss-cut, clear, holographic, sticker packs |
| Hard goods | Patches (embroidered, PVC), enamel pins, keychains |
| Specialty | Phone cases, notebooks, mouse pads |

## Production Methods

| Method | Best For |
|--------|---------|
| Screen print | High-volume apparel; 1–6 colors; most economical at 24+ units |
| DTG (Direct to Garment) | Full-color designs; small runs; no minimum |
| Embroidery | Premium apparel; structured hats; patches |
| Sublimation | All-over print; polyester; drinkware; performance wear |
| Vinyl cutting | Stickers, decals, heat transfer |
| POD platforms | Printful, Printify, SPOD — zero inventory; test designs |

## Output

`campaigns/{{slug}}/creative/design/outputs/retail-design.md` or `design-system/merch/[collection-name].md`

Complete specs: design description, Pantone/CMYK/hex colors, file format requirements, placement sizes, production method notes, cost guidance, and mockup recommendations.

## Dependencies

- **brand-intelligence-center** (required) — brand identity, logo variations, color values
- **art-director** (directs this agent) — visual direction system, merch brief
