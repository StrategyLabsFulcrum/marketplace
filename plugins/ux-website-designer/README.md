# UX/Website Designer

Designs the web experience — landing pages, microsites, user flows, and web components. Produces wireframe descriptions, UX copy, CRO hypotheses, and responsive specifications. Specialist agent — directed by the Art Director.

## What It Does

1. Loads brand and visual standards
2. Maps the user's scrolling journey before designing
3. Produces complete wireframe documents for every page/component
4. Writes all UX copy — form labels, error messages, button text, confirmation states
5. Produces CRO hypotheses (ranked by expected impact)
6. Specifies responsive breakpoints and mobile behavior
7. Flags accessibility requirements for the dev team

## Page/Component Types

| Type | Output |
|------|--------|
| Landing page | Full wireframe — all viewports + UX copy + CRO tests |
| Microsite | Multi-page structure + navigation flow |
| Form / sign-up | Field specs, validation copy, success states |
| Onboarding flow | Step-by-step wireframe with progress indicators |
| Web component | Reusable component spec (modal, card, pricing table) |
| User flow map | Text-based flow diagram (Page A → action → Page B) |

## Output

`campaigns/{{slug}}/creative/design/outputs/ux-wireframes.md`

Complete wireframe, UX copy, responsive notes, CRO hypotheses, and accessibility requirements.

## Dependencies

- **brand-intelligence-center** (required) — brand voice, product details
- **art-director** (directs this agent) — visual direction system, UX brief
- **direct-response-copy** (coordinate) — page copy informs page structure
