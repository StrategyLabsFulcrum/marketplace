# Production Specifications Reference

Technical requirements for all channels and media types. Art Director and design specialists reference this for every execution. All specs are the minimum acceptable standards — when in doubt, go higher resolution.

---

## Digital: Paid Social

### Meta (Facebook + Instagram)

#### Feed — Image
| Format | Dimensions | Aspect Ratio | File Type | Max File Size |
|--------|-----------|-------------|-----------|--------------|
| Square | 1080×1080px | 1:1 | JPG, PNG | 30 MB |
| Portrait | 1080×1350px | 4:5 | JPG, PNG | 30 MB |
| Landscape | 1200×628px | 1.91:1 | JPG, PNG | 30 MB |

- Resolution: 72 PPI minimum (web), supply 2× at 144 PPI
- Safe zone: Keep all text and key elements within 80% of frame (to avoid cropping across placements)
- Text overlay: Under 20% of image area for best delivery
- Color space: sRGB

#### Feed — Video
| Format | Dimensions | Aspect Ratio | Max Duration | File Type | Max File Size |
|--------|-----------|-------------|-------------|-----------|--------------|
| Square | 1080×1080px | 1:1 | 240 min | MP4, MOV | 4 GB |
| Portrait | 1080×1350px | 4:5 | 240 min | MP4, MOV | 4 GB |
| Landscape | 1280×720px | 16:9 | 240 min | MP4, MOV | 4 GB |

- Frame rate: 24, 25, or 30 fps
- Bitrate: Minimum 1 Mbps
- Audio: AAC, 128 kbps+
- Captions: Always include — most video plays without sound
- First 3 seconds: Must be thumb-stopping — lead with visual payoff, not logo

#### Stories and Reels — Image
| Dimensions | Aspect Ratio | File Type | Max File Size |
|-----------|-------------|-----------|--------------|
| 1080×1920px | 9:16 | JPG, PNG | 30 MB |

- Safe zone top: 250px (status bar + profile UI)
- Safe zone bottom: 400px (CTA bar and navigation)
- Content area: Rows 250–1520px
- Do not place text or key imagery outside the safe zone

#### Stories and Reels — Video
| Dimensions | Aspect Ratio | Max Duration | File Type |
|-----------|-------------|-------------|-----------|
| 1080×1920px | 9:16 | 60 sec (Stories) / 90 sec (Reels) | MP4, MOV |

- Frame rate: 23.98–60 fps
- Minimum resolution: 1080×1920px
- Reels: Hook must land within first 1 second

#### Carousel
- Each card: 1080×1080px (square) or 1080×1350px (portrait)
- 2–10 cards per carousel
- First card must be the strongest visual — this is what stops the scroll

## Digital: Email

### Email Header / Hero Image
| Use | Dimensions | File Type | Max File Size |
|-----|-----------|-----------|--------------|
| Desktop hero | 600–700px wide | JPG, PNG | 200 KB |
| Mobile (2:1 ratio) | 600×300px | JPG, PNG | 200 KB |

- Email renders at 600px on desktop — never design wider
- Always design with images OFF in mind — use background colors and alt text
- Total email weight (all images): Under 600 KB for reliable delivery
- Animated GIFs: First frame must convey full message (Outlook doesn't animate)
- Color space: sRGB
- All images: Alt text required

### CTA Buttons in Email
- Minimum size: 44×44px tap target (mobile)
- Use background color + HTML text for CTAs — not image-based buttons
- Why: Image-based buttons disappear when images are blocked

## Print: Magazines and Newspapers

### Magazine — Full Page

| Size | Trim Size | Live Area | Bleed |
|------|-----------|-----------|-------|
| Full page | 8.375×10.875" | 7×9.5" | 8.625×11.125" (0.125" bleed on all sides) |
| Half page H | 7×4.875" | 6.5×4.375" | 7.25×5.125" |
| Half page V | 3.4375×9.875" | 2.9375×9.375" | 3.6875×10.125" |
| Quarter page | 3.4375×4.875" | 2.9375×4.375" | 3.6875×5.125" |
| DPS (Double Page Spread) | 16.75×10.875" | 15×9.5" | 17×11.125" |

- Resolution: 300 PPI minimum at print size
- Color space: CMYK
- File format: PDF/X-1a or PDF/X-4 (confirm with publication)
- Fonts: All fonts embedded or outlined
- Black text: 100K only (not rich black) for text under 12pt
- Rich black for large type/backgrounds: C60 M40 Y40 K100
- Ink density max: 280–320% (confirm with publication)
- Trim marks and slug included

### Newspaper

## Print: Direct Mail

### Postcard
| Size | Dimensions | Notes |
|------|-----------|-------|
| 4.25×5.5" | Trim: 4.25×5.5" | USPS Standard — lowest postage |
| 4×6" | Trim: 4×6" | Common size |
| 5×7" | Trim: 5×7" | Popular for promotions |
| 6×9" | Trim: 6×9" | USPS Standard |
| 6×11" | Trim: 6×11" | High-impact standard |

- Bleed: 0.125" on all sides
- Live area: 0.25" inside trim on all sides
- Resolution: 300 PPI minimum
- Color space: CMYK
- USPS indicia: 0.25" from top, 0.5" from right edge, on address side
- Address area: Lower right quadrant of address side — keep clear of design elements

### Self-Mailer / Brochure
- Standard tri-fold: 8.5×11" flat (folds to 3.67×8.5")
- Design panels in order: back cover (1), inside left (2), inside center (3), inside right (4), front cover (5), mailing panel (6)
- Spine/fold panels: Slightly narrower (approximately 0.0625" per fold)
- Bleed: 0.125"

## Out-of-Home (OOH)

### Billboard

| Type | Dimensions | Notes |
|------|-----------|-------|
| Bulletin / Large | 14×48 ft | Most common — high-traffic highways |
| Poster | 10.5×36 ft | Urban and suburban |
| Junior Poster | 6×12 ft | Neighborhood |
| Digital Billboard | 14×48 ft displayed | Supply as 3:1 ratio image, 72 PPI |

**Critical design rules for billboards:**
- Maximum 7 words of copy — preferably 5 or fewer
- Text: Minimum 3 feet tall when printed (scale up from design file)
- No fine print — nothing below 2 feet at full size is readable at speed
- Resolution: 300 PPI at 1/10 scale (file is 1/10 of print size). Example: 14×48 ft billboard = 1.4×4.8" file at 300 PPI
- Color space: CMYK (static vinyl) or sRGB (digital screens)
- Format: PDF (print), JPG or PNG (digital display)
- Viewing distance: Design for 500 ft at 65 mph — contrast and simplicity are everything

### Transit — Bus Shelter
| Type | Dimensions | Notes |
|------|-----------|-------|
| Poster (interior) | 46×67" | Close viewing — more copy allowed |
| Panel (exterior) | 46×67" | Standard |
| King poster | 30×144" | Side of shelter |

- Resolution: 100–150 PPI at final print size
- Viewers dwell longer than billboards — can use more copy (10–15 words max)
- Include URL or QR code (viewers can act on it)

### Transit — Bus Side and Wrap

## Packaging

### General Packaging Rules
- Resolution: 300 PPI minimum at final print size
- Color space: CMYK (offset or flexographic printing)
- Spot colors / Pantone: Define all spot colors — do not use approximate CMYK conversions for brand colors without proof
- Dielines: Provided by package manufacturer — always design on the die structure
- Safety zone: All critical content (brand name, key claims) must be inside 0.125" from any fold or cut line
- Barcodes: Must meet GS1 standards; minimum size 80% of standard; test scan before production
- Regulatory copy: Confirm all required label elements (ingredients, net weight, country of origin, etc.) with legal before production

### Common Packaging Formats

| Format | Notes |
|--------|-------|
| Folding carton (box) | Request die template from printer; score/fold lines are part of design |
| Flexible pouch | Accounts for registration shift in flexographic printing — avoid fine detail at edges |
| Shrink sleeve | Cylindrical distortion compensation required; use vendor template |
| Label (pressure-sensitive) | Substrate affects color; request physical proof |

### Print Process Considerations
- **Offset lithography** (high volume, premium): CMYK + spot Pantone; finest detail; consistent color
- **Flexographic** (packaging, labels): Slight registration variance; avoid very fine lines; test halftone angles
- **Digital** (short run, variable): CMYK only; excellent for small quantities; color profile varies by press

## File Delivery Standards

### Naming Convention
`{{brand}}_{{campaign-slug}}_{{asset-type}}_{{format}}_{{version}}.{{ext}}`

Examples:
- `acme_2026-03-spring_social-feed_meta-1080x1080_v1.jpg`
- `acme_2026-03-spring_billboard-14x48_print_v2.pdf`
- `acme_2026-03-spring_email-hero_600x300_final.jpg`

### Version Control
- Working files: `_v1`, `_v2`, `_v3`
- Client-ready: `_draft`
- Approved for production: `_final`
- Never deliver a file named "final_FINAL" or "final_v3_USE_THIS_ONE"

### Package Contents for Production Handoff
For any print or production delivery:
- [ ] Final PDF (correct version, correct color space)
- [ ] Fonts folder (or all fonts outlined)
- [ ] Links folder (all placed images at full resolution)
- [ ] Production notes (paper/substrate spec, special finishes, vendor contact)
- [ ] Color proof sign-off (physical or digital proof approved before print run)
