# /best-practices-review

Crawl official platform documentation and surface recommended updates to agent reference files. Reviews Meta, Google, Klaviyo, TikTok, LinkedIn, and other platforms for changes that should be reflected in agent behavior.

## How to Invoke

**Full review — all platforms:**
```
/best-practices-review
```

**Specific platform:**
```
/best-practices-review meta
/best-practices-review google
/best-practices-review klaviyo
/best-practices-review tiktok
```

**Specific topic:**
```
/best-practices-review email-deliverability
/best-practices-review video-specs
/best-practices-review attribution
/best-practices-review targeting
```

## What You Get

A structured update report with:
- High priority changes (must act within 7 days)
- Medium priority changes (act within 30 days)
- Low priority / informational items
- Exact before/after text for every recommended reference file update

No changes are made without your approval. You review each recommendation and confirm before anything is written.

## Recommended Cadence

| Schedule | Scope |
|---------|-------|
| Weekly | Quick scan for breaking announcements |
| Monthly | Full active platform review |
| Quarterly | Comprehensive review including benchmarks |
| As needed | When a major platform update is announced |
